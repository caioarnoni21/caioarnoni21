## Projeto em destaque · WorkSense

**TCC em Ciência da Computação — projeto em equipe, em desenvolvimento.**

O WorkSense integra **Telegram, n8n, PostgreSQL, Trello e Ollama** para simular interações profissionais, executar ações sobre tarefas e registrar dados para análise posterior. A IA conversacional utiliza o modelo **Qwen 2.5 3B**, com serviços executados em uma VPS com Docker.

O projeto já reúne o bot, os fluxos de integração e o registro das interações. A análise em Python, os testes automatizados e as visualizações fazem parte das próximas etapas descritas no repositório.

[**Conheça o WorkSense →**](https://github.com/Matias2335/TCC_WorkSense)
