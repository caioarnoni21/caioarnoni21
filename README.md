## 🚀 Projetos em destaque

### 🧠 WorkSense — TCC

Projeto em equipe, em desenvolvimento, que integra **Telegram, n8n, PostgreSQL, Trello e Ollama** para simular interações profissionais, executar ações sobre tarefas e registrar dados para análise posterior.

- **Automação:** workflow no n8n para receber mensagens do Telegram e integrar operações com o Trello.
- **Banco de dados:** PostgreSQL para armazenar vínculos de usuários, memória conversacional e registros de interações.
- **IA conversacional:** Ollama com o modelo **Qwen 2.5 3B** para responder mensagens e dúvidas.
- **Infraestrutura:** serviços executados em uma VPS com **Docker**.
- **Próximas etapas descritas no projeto:** análise em Python, testes automatizados e visualizações.

🛠️ `n8n` `PostgreSQL` `Docker` `Ollama` `Telegram Bot API` `Trello API`

[**Ver repositório do WorkSense →**](https://github.com/Matias2335/TCC_WorkSense)
